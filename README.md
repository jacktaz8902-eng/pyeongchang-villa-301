# 평창빌라 301호 · 모주희의 집착

모바일 우선 인터랙티브 방탈출/비주얼노벨 게임 (단일 HTML, 외부 의존성 없음).

- 도어락 4자리 퍼즐(정답 유도: UV 힌트 + 흑연 지문)
- 복도 아이템 획득 → 방 내부 탐색 → 다중 엔딩
- Web Audio 합성 사운드, 세이프에어리어/터치 최적화

## 301호 내부 — 오브젝트 로직

방은 단순 클릭 나열이 아니라 서로 물린 시스템으로 굴러갑니다.

| 시스템 | 내용 |
|---|---|
| 손전등 배터리 | 탐색 중에만 소모(대사/모달 중엔 정지). 빛의 반경이 잔량에 비례해 줄고, 28% 아래부터 깜빡임. 0%가 되면 암전 — 단 **1회만** 자비(22% 복구) |
| 소음 게이지 | 시끄러운 조사(옷장 +26, 상자 +18, 침대 +12…)마다 상승. 임계치에서 경고 연출이 뜨고, **숨기 QTE의 제한시간을 8초 → 3.6초까지 깎는다** |
| 진실 게이지 | 단서 11종. 천장(최종)은 *편지 3조각 + 노트북 해제 + 휴대폰 복구*가 모두 끝나야 열린다 |
| UV 라이트 | 방에서 재사용. 벽·거울·바닥의 흔적이 드러나지만 **배터리를 2.5배** 먹는다 |

조사 대상은 서로를 연다: 침대를 뒤져야 **철제 상자·휴대폰**이 나오고, 상자는 복도에서 주운 **철사**로만 열리며(안에 여분 건전지), 휴대폰은 책상에서 **충전기**를 찾아야 켜지고, 검은 노트북의 4자리 비밀번호는 **액자 뒤**에 적혀 있다.

### 숨기 QTE

옷장을 열면(=크게 소리를 내면) 문 앞에 발소리가 선다. 선택지는 침대 밑 / 옷장 / 커튼 뒤 — **정답은 미리 조사해 둔 단서가 알려준다.** 옷장 뒤판엔 사람이 지나갈 구멍이 뚫려 있고, 창밖에선 누가 이 창을 보고 있다. 안 봤다면 찍어야 한다.

### 엔딩

- **TRUE END · 세 번째 사람** — 천장의 붉은 렌즈까지 도달
- **BAD END** 4종 — 암전 / 발각 / 벽 속의 손 / 커튼 아래

배드 엔딩에선 `이 방부터 다시`로 복도를 건너뛰고 재도전할 수 있습니다.
